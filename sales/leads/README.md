# Leads

Real prospect contact data is deliberately **not** stored in this repository. The repository is public, and
counselors and schools did not agree to have their names or addresses published. The lead list lives outside the
repo, with the founder. Do not commit names, email addresses, phone numbers or meeting notes about real people here;
in repo documents, describe a prospect by role (for example "a private-school director of college counseling").

A lead record (kept outside the repo) contains:

| Field | Example |
|---|---|
| Contact name and email address | (outside the repo only) |
| Role | Director of college counseling, independent counselor, essay coach |
| Organization type | Private school, public high school, solo practice, coaching business |
| City and state | Providence, RI |
| Public source the contact came from | School website staff page, professional directory |
| Batch | e.g. Rhode Island, Nov 2026 |
| Date first emailed | 2026-11-25 |
| Email version and attachments sent | pitch email version, `calliper-overview-email-v1.pdf` |
| Status | no reply / replied / meeting proposed / meeting held / declined / unsubscribed |
| Meeting date | if any |
| Next step and due date | follow-up email, send sample report |
| Notes | what they asked for, objections |
