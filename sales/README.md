# Sales

Outreach material for counselors and schools.

| File | What it is |
|---|---|
| `calliper-overview-v1.pdf` | Overview a prospect receives: the three features and what is available now (built by `product/engine/scripts/make_pitch_docs.py`) |
| `calliper-overview-email-v1.pdf` | Lightweight version of the overview for email attachments |
| `pitch-email-v1.md`, `-v2.md`, `-v3.md` | Early pitch-email drafts, written while the product was still called UNIMATH (kept as written) |
| `pitch-email-v4-private-counselor.md`, `pitch-email-v4-essay-coach.md` | Current cold emails (under 120 words), from `research/report_review/pitch_v4.md` |
| `DATA_TERMS_DRAFT.md` | Data terms draft, to review with a lawyer before use |
| `leads/` | What a lead record contains. Real contact data is kept outside this repo. |

The cold email tested on 36 simulated buyer personas is generated by `research/make_emails_v2.py`; results are in
`research/results_v2.md`. The 2-page technical note sent with outreach is `product/reports/calliper-technical-note-v1.pdf`.

`pitch-email-v3.md` (essay-planning pitch) should not be sent until:
1. the prompt-pair matrix is human-scored for the schools it names ([N] in the email),
2. the similarity test (E5) is re-run on held-out human scores and beats a constant guess,
3. the worked example is replaced with real numbers from 2-3 students' actual writing,
4. the founder, company, price and contributor-benefit placeholders are filled in.
