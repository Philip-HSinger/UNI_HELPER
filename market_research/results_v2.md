# Pitch simulation v2: the Calliper email (2026-11-24)

Email: the user's final pitch (emails/<id>.md, generated by make_emails_v2.py with one public-profile line per
persona), Calliper_overview.pdf as attachment text, a one-week follow-up. Seller replies by fresh agents using only
product_facts.md v2 (which now includes the true methods and validation status). Buyers: one isolated agent per
persona, continued across stages.

| Stage | Result |
|---|---|
| Opened first email | 7/36 (19%) |
| Opened follow-up | 0/29 |
| Replied | 7/7 openers |
| TRIAL | 4 (p04 private-school counselor, p09 quant solo IEC, p23 quant parent, p24 anxious parent) |
| INTERESTED-NO-COMMIT | 1 (p15 app founder, wants API) |
| DECLINED | 2 (p08 charter network: no low-income/aid modelling, no scale; p20 India agency: no international model, no white-label) |
| GHOSTED | 29 |
| Would pay now | p23 $100, p24 $300; all counselors $0 until validated |

Findings
- Main blocker for non-openers among counselors: unwilling to send a stranger a student's SAT/GPA/list (privacy
  agreements, client confidentiality); vendor fatigue in December; "a college student" framing for some.
- Every engaged reader asked: how the dependence is estimated (answer: set, not fitted), what the 3-11% range is
  (sensitivity range; PDF wording fixed), real-outcome validation (none yet), test-optional handling, GPA (asked for
  but not used). Honest answers increased trust.
- Follow-up that repeats the ask gets nothing.

Deviations from protocol (manager notes)
- Buyers ran as general-purpose agents told to read only their packet file (the sim-buyer type grants all tools).
  Final-stage agents used 4 tool calls instead of 2; not audited further.
- T0 open rate (7/36) exceeded the 6/36 re-run threshold; the 24-item-inbox re-run was not done (compute), so the
  open rate is likely overstated.
- One seller exchange per thread (protocol allows two); final verdicts taken after it.
- v1 emails, fact sheet and transcripts archived under v1/.
