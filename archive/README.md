# Archive

Superseded or unrelated material, kept for history. Nothing here is part of the current Calliper product.

- `old-web-app/`: *Application Efficiency Guide*, the student-facing React + Supabase site this repository started
  as (August 2026). Its GitHub Pages workflow is archived in `old-web-app/.github/` and no longer runs.
  `old-web-app/supabase/seed_source.schools.json`, `update_five_schools.sql` and `scripts/generate_seed_sql.py`
  are still the sources that `product/engine/scripts/build_catalog.py` reads to rebuild the engine's catalog.
